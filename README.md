# retinal-image-disease-classification
Репозиторий группового проекта группы 47 магистратуры ИИ26 НИУ ВШЭ. Цель проекта - построить модель для классификации изображений глазного дна и сделать доступной в виде веб-сервиса.

# План работы

1. EDA датасета [ODIR-5K](https://odir2019.grand-challenge.org/dataset/), определение дисбаланса классов, анализ свойств изображений (качество, яркость, цветовое пространство) и данных о пациентах (пол, возраст), определение сложных случаев (пр. изображения с несколькими классами или разная степень влияния заболевания на оба глаза). Возможно поиск преобразований, которые позволят лучше визуально выявлять признаки заболеваний. Поиск потенциально совместимых датасетов.
2. Изучение существующих подходов в решении задачи классификации изображений глазного дна (одного глаза и модели, учитывающие оба). Сравнение архитектур моделей и подходов при их обучении. Реализация бейзлайн модели классического ML на основе признаков изображений выделенных в пункте выше или эмбеддингах изображений, полученных простой предобученной моделью, (должен быть чуть лучше наивного бейзлайна по распределению классов). Зафиксировать метрики, которые будут использованы для оценки моделей.
3. Реализовать модель глубинного обучения, которая даст результат выше бейзлайна. Построить архитектуру, повышающую точность при использовании парных изображений?
4. Создать вебсервис для презентации решений. Исходя из выбранной архитектуры, можно показывать разное в дополнение к просто метрикам: saliency map для произвольного изображения глаза или box-ы обнаруженных объектов, если будет добавлен этап с детекцией и т.п.
5. Доработать лучшие архитектуры моделей, попробовать разные комбинации преобразований в обучении. Проверить, возможно ли перенести полученные архитектуры на другие датасеты с сохранением точности. Улучшение UI-UX вебсервиса.
