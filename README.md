## Тема проекта

**Мультилейбл-классификация заболеваний глаза по парным снимкам глазного дна с веб-сервисом для демонстрации предсказаний.**

Цель — провести исследование архитектур и подходов к классификации изображений глазного дна (от классического ML до глубинных моделей, учитывающих оба глаза), на его основе построить модель, которая по изображениям левого и правого глаза пациента определяет наличие патологий, и сделать её доступной в виде веб-сервиса с визуализацией областей, повлиявших на решение модели.

## План работы

1. **EDA.** Разведочный анализ датасета [ODIR-5K](https://odir2019.grand-challenge.org/dataset/): оценка дисбаланса классов, анализ свойств изображений (качество, яркость, цветовое пространство) и данных о пациентах (пол, возраст), выявление сложных случаев (например, изображений с несколькими классами или разной степенью поражения левого и правого глаза). Поиск преобразований, позволяющих лучше выявлять визуальные признаки заболеваний, и потенциально совместимых датасетов.
2. **Обзор литературы и бейзлайн.** Изучение существующих подходов к классификации изображений глазного дна: моделей для одного глаза и моделей, учитывающих оба. Сравнение архитектур и подходов к их обучению. Реализация бейзлайн-модели классического ML на признаках, выделенных на этапе EDA, или на эмбеддингах простой предобученной модели; бейзлайн должен превосходить наивное предсказание по распределению классов. Фиксация метрик для оценки моделей.
3. **Модель глубинного обучения.** Реализация модели глубинного обучения, превосходящей бейзлайн. Исследование архитектур, повышающих точность за счёт использования парных изображений.
4. **Веб-сервис.** Создание веб-сервиса для презентации решений. Помимо метрик, в зависимости от выбранной архитектуры сервис может показывать saliency map для произвольного снимка глаза, bounding box-ы обнаруженных объектов (если будет добавлен этап детекции) и т. п.
5. **Доработка.** Улучшение лучших архитектур, эксперименты с комбинациями преобразований при обучении. Проверка переносимости моделей на другие датасеты с сохранением точности. Улучшение UI/UX веб-сервиса.
